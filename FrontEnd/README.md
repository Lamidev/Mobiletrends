# Mobiletrends Systems Limited 🚀

Mobiletrends Systems Limited is a modern, high-performance E-commerce platform specialized in smartphones, laptops, and premium electronics. Built with Next.js 14 App Router, TypeScript, Tailwind CSS, Express, MongoDB, and Resend.

## ✨ Key Features

- **🛍️ Complete Shopping Flow:** Browse products, filter by category/brand/price, add to cart, and secure checkout.
- **🔐 Advanced Security:** 
  - JWT Authentication via secure HttpOnly cookies and Bearer tokens.
  - Protection against XSS, CSRF, and account enumeration.
  - Zero password hash leakage to the frontend.
- **💳 Payment Integration:** Fully integrated with **Paystack** for secure Nigerian payments.
- **📱 Responsive Design:** Optimized for all devices, featuring a seamless mobile navigation and a clean, premium UI using **Shadcn UI** and **Tailwind CSS**.
- **🔍 Smart Search & Filtering:** Instant live search with debounced querying, clear buttons, and fallback showcase products.
- **📧 Automated Emails:** Transactional emails powered by **Resend** with DKIM, SPF, and DMARC verification.
- **📂 Image Management:** Cloud-hosted images via **Cloudinary**.
- **⚡ Performance First:** Global scroll management, preloader curtain, and optimized state management with **Redux Toolkit**.
